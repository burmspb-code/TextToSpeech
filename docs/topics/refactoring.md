## Цель
Улучшить структуру и поддерживаемость кода TextToSpeech без изменения видимого пользователю поведения.

## Решено
- Агентские файлы игнорируются локально и глобально (`~/.config/git/ignore`); `docs/topics/` — исключение и хранится в git.
- `docs/*.py` — код проекта, под ignore не попадает.
- `edge` и `silero` — extras (`poetry install -E ...`), ruff — в группе `dev`, проверки обязательны после изменения кода.
- `torch` и `torchaudio` ограничены 2.11.x; Python — 3.14.x из-за ограничения `triton <3.15`.
- GUI переписан с Tkinter на PyQt6: `QMainWindow`, `QPlainTextEdit`, `QComboBox`, `QFileDialog`, `QMessageBox`; очередь событий из потока синтеза разбирается через `QTimer`.
- При открытии окно центрируется по доступной области экрана (`center_on_screen()` вызывается в `build_window()`).
- Silero добавлен как второй локальный движок: русская модель `v5_5_ru`, пять реальных дикторов, качество 8/24/48 кГц; скорость реализована через phase vocoder.
- Системная шапка Windows отключена: кнопки «свернуть / развернуть / закрыть» живут в правой части строки меню на одном уровне с «Настройки» и «О программе».
- «О программе» — пункт верхнего уровня с собственным диалогом и рабочей кнопкой OK; выбор качества убран из настроек (Silero 48 кГц, Piper medium).
- Окно без системной рамки имеет небольшие скруглённые углы и отступ содержимого от края; иконка приложения хранится в пакете и показывается перед названием.

## Сделано
- Проверки зависимостей и окружения: `pip check`, `poetry check --lock`, Poetry и IDE используют один `.venv`; версии приведены к lock.
- Исправлены команды установки extras, наведён порядок в `.idea`, добавлен ruff и исправлены его замечания.
- `src/texttospeech/app.py` переписан под Qt; сохранены поведение правок/сохранения, кодировок, выбора голоса и скорости, фонового синтеза и прогресса.
- Тесты переписаны под Qt с оффскрин-платформой (`tests/conftest.py`); `docs/screenshot.py` и `docs/screenshot_edit.py` теперь снимают `QWidget.grab()`.
- Убраны все упоминания Tkinter из кода и документации; README и `pyproject.toml` обновлены.
- Добавлено центрирование окна при запуске и тест на него; подпись о движке сдвинута сразу после названия у левого края и выровнена с ним по базовой линии текста.
- Системные `QComboBox` заменены на `DropdownButton` (кнопка + `QMenu`) с нарисованным шевроном и современным меню.
- Каталог голосов сокращён до четырёх русских дикторов (`ru_RU`);иностранные модели удалены.
- Появились меню «Настройки» (качество, голос, скорость через `QWidgetAction` с `DropdownButton`) и «О программе» (движок и инструкция).
- На главной странице убрана информация о движке, добавлена кнопка «Вставить текст из буфера»; выбор голоса/скорости перенесён в меню.
- Селектор качества работает с реально существующими моделями: для `ru_RU` доступен только `medium` (`low`/`high` на Hugging Face отсутствуют).
- Проверки после изменений GUI: `ruff check .` — All checks passed; `pytest -q` — 88 passed.
- Интеграция Silero: каталог голосов и качество грузятся из настроек, модель скачивается с прогрессом и кэшируется по `model_id`, добавлены тесты движка и переключения.
- Исправлены реальные сбои Silero: оборванная загрузка больше не считается моделью (проверка zip + докачка), каталог дикторов приведён к пяти реальным дикторам `v5_5_ru`, пустой WAV и неизвестный диктор теперь дают ошибку; реальный синтез и GUI-поток проверены.
- Проверки после исправлений: `ruff check .` — All checks passed; `pytest -q` — 108 passed (1 warning из `silero-tts`).
- Модели перенесены в `models/piper` и `models/silero`; `expose_silero_model()` подключает модель проекта к кэшу `silero-tts` хардлинком, скрипты в `docs/` и тесты используют новые пути.
- Silero стал движком по умолчанию с голосом Ксения (`xenia`) и высоким качеством 48 кГц; качество, голос и скорость запоминаются отдельно для Piper и Silero и восстанавливаются при переключении.
- Проверки после последних изменений: `ruff check .` — All checks passed; `pytest -q` — 112 passed (1 warning из `silero-tts`); реальный синтез Piper и Silero из `models/` — успешно.
- Своя рамка окна: `FramelessWindowHint`, кнопки в `QMenuBar.setCornerWidget()`, перетаскивание за строку меню и изменение размера за края; добавлены тесты на отсутствие системной шапки и кнопки в правом углу.
- Исследовано качество Silero: частота 8/24/48 кГц меняет частоту дискретизации WAV и полосу vocoder (f95 ≈ 1.0 / 9.3 / 6.4 кГц в зоне тестовой фразы), но не длительность речи; 48 кГц остаётся значением по умолчанию.
- Убрано вложенное меню «О программе»: справка открывается по прямому действию в `QMenuBar`, диалог реализован на `QDialog` с кнопкой OK, связанной с `accept()`; тест проверяет, что OK действительно закрывает окно.
- Убран селектор качества: `selected_quality` возвращает фиксированное значение движка, список голосов и память настроек работают без `quality_box`; README и справка обновлены.
- Исправлен клик по «О программе»: обработчик перетаскивания больше не перехватывает отпускание кнопки мыши над пунктом меню; добавлен тест реального клика по действию.
- Кнопка закрытия получила тот же стиль без рамки, что и кнопки свернуть/развернуть; добавлена проверка общего CSS-правила.
- Скруглены углы окна (`WA_TranslucentBackground` + радиус в стилях), увеличен отступ содержимого, у пунктов меню и кнопок шапки добавлены внутренние отступы, чтобы выделение не прилипало к краю.
- Иконка `tts.png` скопирована в `src/texttospeech/assets/`, добавлена в пакет через `pyproject.toml`, установлена как `windowIcon` и показана миниатюрой перед названием в шапке.
- Правый верхний угол проверен и исправлен: виджет кнопок стал прозрачным, радиус задан и в стилях, и через `setMask()`; тест проверяет, что угол действительно вырезан из области окна.
- Диалог несохранённых изменений получил русские кнопки «Сохранить», «Не сохранять» и «Отмена» вместо стандартных английских подписей Qt.
- Шкала прогресса переделана в `SoundWaveProgress`: анимированная звуковая волна стоит в шапке сразу после названия и показывает позицию воспроизведения WAV через `QMediaPlayer` (`positionChanged` / `durationChanged`), а не ход синтеза. Анимация идёт только во время проигрывания; по окончании файла волна доходит до 100%. Кнопки «Стоп» и «Озвучить» прижаты к правому краю нижней панели и не растягиваются.
- В индикаторе воспроизведения три волны: синяя, фиолетовая и зелёная (третья линия, которая стала заметной после увеличения амплитуды). Каждая рисуется одной линией со своей амплитудой и фазой, все обрезаются по позиции и заполняются слева направо. Фон дорожки стал светло-бирюзовым вместо серого/фиолетового. Тест проверяет по пикселям все три цвета, границу прогресса и цвет дорожки.
- Тесты проверяют расположение волны в шапке, выравнивание кнопок, связь волны с позицией воспроизведения и отсутствие событий прогресса из потока синтеза.
- Прогресс синтеза вынесен в `ProgressButton`: фон кнопки «Озвучить» заполняется слева направо градиентом (`synthesis_progress`: 40% на загрузку, 55% на синтез, 100% после сборки WAV); при ошибке заливка сбрасывается. События из рабочего потока разбираются пачкой за один тик, поэтому заливка дорисовывается таймером по шагам, а не прыгает сразу на 100%. Волна в шапке по-прежнему отвечает только за воспроизведение. Тесты проверяют направление заливки, последовательность 47 → 95 → 100 и плавный переход 0 → 100.
- Проверена жалоба на «обрыв на первом предложении»: на точном тексте пользователя `split_text()` даёт 2 фрагмента (542 и 298 символов), финальный WAV длится 50,09 c, оба фрагмента не тихие. Причина была в конце воспроизведения: Qt присылает `StoppedState` с `BufferedMedia` и `position == duration` раньше, чем `EndOfMedia`, из-за чего волна сбрасывалась в 0. Теперь конец файла определяется и по позиции, и по `EndOfMedia`: волна остаётся заполненной, кнопка «Стоп» выключается, статус «Воспроизведение завершено.». Ошибки плеера показываются русским статусом. Проверено реальным проигрыванием 50-секундного файла: последнее значение волны 100.
- Журнал восстановлен как единственный файл `texttospeech.log` рядом с дорожками вместо вывода в консоль: `configure_logging()` в `main()` направляет stderr (включая нативный FFmpeg через fd 2) в файл и подключает `loguru` к тому же потоку. Файл перезаписывается при запуске, а при достижении 10 МБ стирается и продолжается с начала; архивов не создаётся. `loguru` подключается только если пакет установлен (он приходит с `silero-tts`), поэтому Piper-сборка без него работает. Повторный вызов при смене папки переносит журнал. Проверено: логи синтеза и строки FFmpeg (`Input #0`, `av1_mf`) попали в файл, консоль пуста.
- Все генерируемые файлы перенесены из домашнего `~/.local/share/texttospeech/` в каталог проекта (`paths.py`, `output/` по умолчанию). Старые файлы оттуда удалены; один WAV остался заблокирован запущенным GUI-процессом `main.py` и будет удалён после закрытия окна.
- Фрагменты `parts/part_*.wav` удаляются сразу после успешной склейки, пустая папка `parts/` тоже убирается. При ошибке склейки фрагменты сохраняются.
- В меню «Настройки» добавлена кнопка «Папка файлов»: `QFileDialog.getExistingDirectory`, выбор сохраняется через `QSettings("TextToSpeech", "TextToSpeech")`, при смене папки журнал переносится туда же. Синтез использует `self.output_dir`, а не глобальный путь.
- Финальные проверки: `ruff check .` — All checks passed; `pytest -q` — 136 passed (1 warning из `silero-tts`); `poetry check --lock` — All set.
