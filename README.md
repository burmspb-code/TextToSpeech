# TextToSpeech

Офлайн-приложение для синтеза речи из текста. Два локальных движка —
Silero (основной) и [Piper], графический интерфейс — PyQt6.

## Как это работает

```
текст
  ├─ Piper:  espeak-ng → фонемы → Piper (.onnx) → WAV
  └─ Silero: multilingual VITS (.pt, PyTorch)   → WAV
```

Оба движка работают **полностью локально**. Интернет нужен один раз —
чтобы скачать модель (у Piper ~60 МБ, у Silero ~140 МБ). После этого
приложение работает без сети.

Это проверено тестом `docs/test_offline.py`, который блокирует все сетевые
вызовы и синтезирует речь.

## Установка

```bash
poetry install
```

Дополнительные движки ставятся по желанию:

```bash
poetry install -E edge      # онлайн, Microsoft
poetry install -E silero    # офлайн, PyTorch (~2.5 ГБ)
```

## Запуск

```bash
poetry run texttospeech
```

## Разработка

Проверки обязательны после любого изменения кода:

```bash
poetry run ruff check .
poetry run pytest -q
```

Тесты интерфейса запускаются в оффскрин-режиме Qt (`tests/conftest.py`),
поэтому для них не нужен видимый экран.

Поддерживается Python 3.14.x. Движки `edge` и `silero` ставятся как extras
(см. «Установка»), `torch` и `torchaudio` фиксируются на совместимой ветке 2.11.

## Как пользоваться

1. **Открыть файл** — кнопка «Открыть файл» или Ctrl+O
2. **Вставить текст из буфера** — кнопка на главной странице, вставка идёт
   в позицию курсора
3. **Править текст** — поле редактируемое, можно писать прямо в окне
4. **Озвучить** — синтез идёт в фоне, окно остаётся отзывчивым. Его ход
   виден по фону кнопки: заливка плавно растёт слева направо и доходит до
   конца только после сборки WAV. Волновой индикатор в шапке после
   названия показывает уже ход воспроизведения готового файла: синяя,
   фиолетовая и зелёная волны заполняют бирюзовую дорожку слева направо.
   В конце файла волна остаётся полностью заполненной. Кнопки
   «Стоп» и «Озвучить» прижаты к правому краю нижней панели
5. **Сохранить** — Ctrl+S, если правили файл

Настройки синтеза (движок, голос, скорость) вынесены в меню
**«Настройки»**. Голос и скорость запоминаются отдельно для каждого
движка: переключение Piper ↔ Silero не сбрасывает выбор. Качество не
настраивается: у Silero зафиксировано 48 кГц, у Piper доступен только
уровень medium.
Сведения о движках и краткая инструкция открываются по пункту верхнего
меню **«О программе»**; на главной странице этой информации нет.

Окно открывается без стандартной шапки Windows, с небольшим скруглением
углов и отступом содержимого от края. Иконка приложения стоит перед
названием в шапке. Плоские кнопки «свернуть», «развернуть/восстановить»
и «закрыть» находятся справа в той же строке, где «Настройки» и
«О программе». Окно можно перетаскивать за пустое место этой строки и
менять размер за его края.

Текст можно не только править, но и писать с нуля — без файла
приложение работает так же. Пока есть несохранённые правки, в
заголовке стоит звёздочка, а при открытии другого файла или закрытии
программы она спросит, что с ними делать.

Приложение читает **поле**, а не файл: все правки попадают в синтез.
Кодировка файла запоминается и сохраняется при перезаписи — файл в
windows-1251 останется в windows-1251.

Готовые дорожки по умолчанию складываются в `output/` каталога проекта.
Папку можно поменять в меню **«Настройки» → «Папка файлов»**: выбор
запоминается между запусками. Фрагменты создаются в подпапке `parts/`
и удаляются сразу после успешной склейки WAV.

Журнал работы пишется только в файл `texttospeech.log` рядом с дорожками:
сообщения `silero_tts`, предупреждения FFmpeg и прочая диагностика не
выводятся в консоль. Файл один, при каждом запуске перезаписывается, а при
достижении 10 МБ содержимое стирается и запись продолжается с начала.

Все скачанные модели лежат в отдельной папке проекта: `models/piper/`
и `models/silero/`. При запуске и выборе голоса приложение берёт модель
именно оттуда; для `silero-tts` она подключается к кэшу пакета через
хардлинк, поэтому вторая копия на диске не создаётся. Папка `models/`
не попадает в git.

## Голоса и качество

В каталоге только русские голоса. У **Piper** — Дмитрий, Денис, Руслан и
Ирина. У **Silero** — Айдар, Бая, Ксения, Евгений и Ксения (вариант
`xenia`): в модели `v5_5_ru` ровно пять дикторов, два из которых носят
похожие имена. Иностранные модели удалены — приложение рассчитано на
русский текст.

Качество зависит от движка и в интерфейсе не меняется:

- **Piper:** уровень `medium` (~60 МБ). В `rhasspy/piper-voices` для `ru_RU`
  нет каталогов `low` и `high` (запрос к ним возвращает 404).
- **Silero:** зафиксировано 48 кГц. Другие частоты (8 / 24 кГц) есть в
  конфиге `silero-tts`, но пункт выбора качества убран из настроек. Один файл
  модели обслуживает всех дикторов, поэтому переключение голоса не
  скачивает ничего заново.

Модель скачивается один раз при первом использовании и дальше работает
офлайн. Разница между дикторами — в тембре, поле и интонации. Оборванная
загрузка не считается готовой: целостность `.pt` проверяется по zip-структуре,
а следующий запуск продолжит скачивание с того же места.
Скорость у Piper задаётся параметром модели, а у Silero применяется к
готовому звуку через phase vocoder — речь ускоряется без сдвига тона.

## Выбор движка

Движок выбирается в меню **«Настройки» → «Движок»**; по умолчанию
Silero с голосом Ксения (`xenia`) и зафиксированным качеством 48 кГц.
Движки сравнивались на одинаковом русском тексте:

| | Piper | Silero | edge-tts |
|---|---|---|---|
| Работает офлайн | **да** | да | нет, нужен интернет |
| Скорость (RTF) | **0.058** | 0.255 | зависит от сети |
| Размер модели | **60 МБ** | 230 МБ | — |
| Зависимости | **44 МБ** | 2.5 ГБ (torch) | лёгкие |
| Уровень сигнала | RMS 4214 | RMS 1983 | — |
| Качество речи | хорошее | **ощутимо лучше Piper** | лучшее |
| Статус | рабочий | рабочий | рабочий, но нестабильный |

RTF (real-time factor) — во сколько раз синтез быстрее реального времени.
Значение меньше 1 — хорошо.

Подробности и замеры: `docs/bench_compare.py`, `docs/bench_piper.py`.

## Известные грабли

**edge-tts иногда падает с `NoAudioReceived`.** Соединение открывается,
но сервер закрывает WebSocket без аудио. Проверено: версия пакета
актуальная, часы верные, DRM-токен генерируется — дело на стороне
сервиса Microsoft. Помогает повтор. Раньше сбой был устойчивым
(три попытки подряд), потом вообще перестал — так что причина
не региональная, как сначала показалось. Поэтому основной движок —
Silero: он и звучит лучше, и от интернета не зависит. Piper остаётся
полностью офлайн-запасным вариантом.

**silero-tts 0.0.5 без `__init__.py`.** Обычный импорт падает:

```python
from silero_tts import SileroTTS   # ImportError
```

Работает прямой импорт подмодуля — его использует `SileroEngine` и
`docs/compare_silero.py`:

```python
from silero_tts.silero_tts import SileroTTS
```

**Python 3.14.** Поддерживается. `piper-tts` собран как `cp39-abi3`,
поэтому ставится без проблем; `onnxruntime` и `torch` имеют
`cp314`-сборки.
