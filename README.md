# TextToSpeech

Офлайн-приложение для синтеза речи из текста. Основной движок — [Piper],
графический интерфейс — Tkinter.

## Как это работает

```
текст
  ↓  espeak-ng      — превращает буквы в фонемы («п р и в е т»)
  ↓  Piper (.onnx)  — нейросеть генерирует звук
WAV-файл
```

Piper работает **полностью локально**. Интернет нужен один раз — чтобы
скачать голос (~60 МБ). После этого приложение работает без сети.

Это проверено тестом `docs/test_offline.py`, который блокирует все сетевые
вызовы и синтезирует речь.

## Установка

```bash
poetry install
```

Дополнительные движки ставятся по желанию:

```bash
poetry install --with edge      # онлайн, Microsoft
poetry install --with silero    # офлайн, PyTorch (~2.5 ГБ)
```

## Запуск

```bash
poetry run texttospeech
```

## Как пользоваться

1. **Открыть файл** — кнопка «Открыть файл» или Ctrl+O
2. **Править текст** — поле редактируемое, можно писать прямо в окне
3. **Озвучить** — синтез идёт в фоне, окно остаётся отзывчивым
4. **Сохранить** — Ctrl+S, если правили файл

Текст можно не только править, но и писать с нуля — без файла
приложение работает так же. Пока есть несохранённые правки, в
заголовке стоит звёздочка, а при открытии другого файла или закрытии
программы она спросит, что с ними делать.

Приложение читает **поле**, а не файл: все правки попадают в синтез.
Кодировка файла запоминается и сохраняется при перезаписи — файл в
windows-1251 останется в windows-1251.

Готовые дорожки складываются в `~/.local/share/texttospeech/`,
фрагменты — в подпапку `parts/`.

## Выбор движка

Движки сравнивались на одинаковом русском тексте:

| | Piper | Silero | edge-tts |
|---|---|---|---|
| Работает офлайн | **да** | да | нет, нужен интернет |
| Скорость (RTF) | **0.058** | 0.255 | зависит от сети |
| Размер модели | **60 МБ** | 230 МБ | — |
| Зависимости | **44 МБ** | 2.5 ГБ (torch) | лёгкие |
| Уровень сигнала | RMS 4214 | RMS 1983 | — |
| Качество речи | хорошее | среднее | **лучшее** |
| Статус | рабочий | рабочий | рабочий, но нестабильный |

RTF (real-time factor) — во сколько раз синтез быстрее реального времени.
Значение меньше 1 — хорошо.

Подробности и замеры: `docs/bench_compare.py`, `docs/bench_piper.py`.

## Известные грабли

**edge-tts иногда падает с `NoAudioReceived`.** Соединение открывается,
но сервер закрывает WebSocket без аудио. Проверено: версия пакета
актуальная, часы верные, DRM-токен генерируется — дело на стороне
сервиса Microsoft. Помогает повтор. Раньше сбой был устойчивым
(три попытки подряд), потом вообще перестал — так что причина
не региональная, как сначала показалось. Именно поэтому Piper
основной движок: от него интернет не зависит вообще.

**silero-tts 0.0.5 сломан.** В пакете нет `__init__.py`, поэтому обычный
импорт падает:

```python
from silero_tts import SileroTTS   # ImportError
```

Работает только прямой импорт подмодуля через `sys.path` — см.
`docs/compare_silero.py`.

**Python 3.14.** Поддерживается. `piper-tts` собран как `cp39-abi3`,
поэтому ставится без проблем; `onnxruntime` и `torch` имеют
`cp314`-сборки.
